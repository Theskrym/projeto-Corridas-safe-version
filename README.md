
# Sistema de Gerenciamento de Corridas

Aplicação web para organizar corridas institucionais, motoristas, veículos, agendamentos e relatórios.

## Dependências do frontend

O frontend requer Node.js 20.x ou 22+. Para instalar as versões travadas e validar dependências:

```powershell
cd frontend
npm ci
npm audit
npm run build
```

O registro das atualizações de segurança está em [docs/dependency-alerts.md](docs/dependency-alerts.md).

## Portfólio de UX

O documento [Portfólio de UX](docs/portfolio-ux.md) reúne a história do projeto, avaliação heurística, planos e registros de testes, acessibilidade, design system, arquitetura da informação, changelog e checklist de apresentação.

> As atividades que dependem de participantes, gravações consentidas, auditorias e arquivos Figma estão identificadas como pendentes até que sejam realizadas e suas evidências anexadas.
